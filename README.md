# Pennywise — A Complete Android Expense Tracker

**SyntecxHub Week 4 Android App Development Internship Project**

Pennywise is an offline-first personal expense and income tracker built strictly with **Kotlin**, **Room Database**, **MVVM Architecture** (UI → ViewModel → Repository → Room DAO), **Kotlin Coroutines**, **RecyclerView** with ViewBinding, **MPAndroidChart**, and **Material Components for Android**.

The default currency is **Pakistani Rupee (PKR)**, formatted with centralized minor-unit arithmetic (integer paisas) to eliminate floating-point rounding errors.

---

## 1. Project Specifications & Requirements Met

| Requirement | Implementation Details |
|---|---|
| **Platform & Language** | Android 8.0+ (API 26+) · Kotlin |
| **UI Framework** | Traditional Android Views with XML layouts & ViewBinding (No Jetpack Compose) |
| **Local Persistence** | SQLite via **Android Room 2.6.1** with entities, DAOs, and singleton AppDatabase |
| **Architecture** | **MVVM**: UI (Activities/Fragments) → ViewModel (LiveData + viewModelScope) → Repository → Room DAO |
| **Currency** | Centralized **PKR** formatting (\`CurrencyFormatter.kt\`) storing amounts in 64-bit integer paisas |
| **Dashboard** | Balance, Total Income, Total Expenses, dynamic monthly spending chart, recent transactions list |
| **Transaction History** | Dedicated screen with search, type filter (Income/Expense), category filter, date-range filter, edit & delete confirmation |
| **Monthly Reports** | Month navigation, Income vs. Expense net difference, category spending breakdown with percentages & charts |
| **Data Export** | Storage Access Framework (\`ACTION_CREATE_DOCUMENT\`) exporting RFC 4180 compliant CSV (\`pennywise_transactions.csv\`) |
| **Visual Design** | Light theme with warm off-white backgrounds, deep navy text, restrained teal accents, 8dp grid spacing |

## 3. Financial Integrity & Calculation Safeguards

Authoritative monetary calculations never use \`Float\` or \`Double\`. Every transaction stores:
\`\`\`kotlin
val amountMinor: Long // e.g., Rs. 1,250.75 is stored as 125075L (paisas)
\`\`\`
- Net Balance = \`Total Recorded Income - Total Recorded Expenses\`
- Selected month net movement = \`Month Income - Month Expense\`
- Category breakdown percentages are derived strictly from aggregate queries over the date range.

## 4. Setup, Build & Run Instructions

### Prerequisites
1. Android Studio Hedgehog (2023.1.1) or newer
2. JDK 17
3. Android SDK API 34 (Android 14)

### Building the Project
\`\`\`bash
# Clone the repository
git clone <repository_url>
cd pennywise

# Run Unit Tests
./gradlew testDebugUnitTest

# Assemble Debug APK
./gradlew assembleDebug
\`\`\`

The generated APK will be available in:
\`app/build/outputs/apk/debug/app-debug.apk\`
